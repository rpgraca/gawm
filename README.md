# Gawm - Gtk Analog Waveform viewer (Modernized Fork)

**Gawm** is a modernized fork of [Gaw](http://www.rvq.fr/linux/gaw.php), a tool for viewing analog data, such as the output of Spice simulations. This fork aims to provide improved visualization.

### Compiling from Source
```bash
./configure
make
sudo make install
```

## Usage

Run the application from the command line:
```bash
gawm [OPTIONS]... [FILE]...

```
